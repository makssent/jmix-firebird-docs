= Getting Started

Firebird support in Jmix is provided by the https://github.com/makssent/jmix-firebird-addon[jmix-firebird-addon^]. This documentation applies to Jmix 3.0. Choose a section based on your task.

== Existing Jmix Project

xref:firebird:index.adoc[Connecting Firebird to a Jmix Project] describes how to configure an existing application to work with a new empty Firebird database, including dependencies, Jaybird, the data source, and Liquibase changelog adaptations.

Liquibase creates the schema for the new database. Migrating existing data from HSQLDB, PostgreSQL, or another DBMS is outside the scope of this section.

== Starting with Jmix from Scratch

The xref:tutorial:index.adoc[tutorial] demonstrates how to create a Jmix application with Firebird step by step, from project setup to the user interface, business logic, and access control.

== Minimal Ready-to-Use Example

The https://github.com/makssent/jmix-firebird-application[jmix-firebird-application^] project was created from the standard Jmix 3.0 template and is already configured to work with Firebird. Instructions for preparing the database, configuring the connection, and running the application are available in the project's README.
