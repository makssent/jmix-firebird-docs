= Введение

Эта документация посвящена использованию Firebird с Jmix. Подробная информация о самой платформе доступна в https://docs.jmix.ru/jmix/intro.html[официальной документации Jmix^].

Здесь собраны инструкции по подключению Firebird к Jmix-проекту, описание особенностей и ограничений интеграции, рекомендации по работе с Liquibase, пошаговый самоучитель и реальный пример переноса готового приложения.

Часть материалов, прежде всего самоучитель, основана на официальной документации Jmix. Эти материалы были адаптированы и дополнены с учётом особенностей работы с Firebird.

Документация рассчитана как на пользователей, которые только знакомятся с Jmix, так и на разработчиков, у которых уже есть существующий Jmix-проект.

== Начало работы

Выберите подходящий сценарий.

[cols="1,3"]
|===

|Вы ещё не знакомы с Jmix
|Начните с xref:tutorial:index.adoc[самоучителя]. В нём вы шаг за шагом создадите Jmix-приложение и настроите его работу с Firebird.

|У вас уже есть Jmix-проект
|Сначала ознакомьтесь с xref:firebird:limitations.adoc[ограничениями Firebird] и оцените, подходит ли Firebird для вашего проекта. Затем перейдите в раздел xref:firebird:index.adoc[Подключение Firebird к Jmix-проекту], где описано добавление поддержки Firebird в существующее приложение.

|Вам нужен практический пример
|Откройте раздел xref:firebird:migration.adoc[Пример переноса приложения на Firebird]. В нём показано, как готовое приложение `jmix-crm` было перенесено с HSQLDB на Firebird, какие изменения для этого потребовались и как был проверен результат.

|===
